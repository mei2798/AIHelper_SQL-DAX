📊 SQL 轉 DAX 小幫手 Web App

本工具內建輕量解析器，會自動抓取您的資料表 (FROM)、條件 (WHERE)、群組 (GROUP BY) 與加總欄位 (SUM) 轉換為對應的 DAX。

✨ 轉換結果 (3種情境)

1. 量值 (Measure) - 適合 Power BI 視覺效果

將此量值拉入矩陣或圖表，DAX 會自動依據畫面上的維度進行 GROUP BY。


            

            

                
2. 計算資料表 (Calculated Table) - 實體化資料表

                
直接在模型中產生一張已分組加總的實體資料表。

                

            

            

                
3. DAX 查詢 (DAX Query) - 適合 DAX Studio 測試

                
可用於 SSMS 或是 DAX Studio 執行並返回資料表結果。
